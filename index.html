HTML CSS JavaScript Profil Dicoding

1. HTML (HyperText Markup Language)

HTML adalah kerangka dasar dari sebuah halaman web. Digunakan untuk menentukan struktur dan konten seperti teks, gambar, dan link.

<h1>Halo Dunia!</h1>

2. CSS (Cascading Style Sheets)

CSS digunakan untuk mengatur tampilan dan tata letak halaman web agar terlihat menarik dan responsif.

body { background-color: #1e1e1e; color: #d4d4d4; }

3. JavaScript

JavaScript memberikan interaktivitas pada web, seperti logika, animasi, dan manipulasi data secara dinamis.
